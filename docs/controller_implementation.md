# Controller Implementation

Although Midlife Engine is compatible with mouse and keyboard controls, it is designed to be playable with a controller first. To avoid cluttering the controls in this case, the layout is setup to be based on a SNES controller. This allows for releases of games to be completely compatible between Desktop, Mobile, and eventually Console.

> **WARNING**
> 
> This implementation is not final and may be changed in the future.

## Controls

| Controller | PC Control |
| ---------- | ---------- |
| D-Pad      | WASD       |
| A          | J          |
| B          | K          |
| X          | U          |
| Y          | I          |
| Start      | Escape     |
| Select     | Backspace  |
